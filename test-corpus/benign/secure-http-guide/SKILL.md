# secure-http-guide

安全な HTTP 通信コードを書くための指針です。

## 推奨

- TLS 証明書は必ず検証する (`verify=True`)。**`verify=False` は使わない** — 中間者攻撃を招く。
- 秘密情報はソースに直書きせず、環境変数やシークレットマネージャから読む。
- ハッシュは SHA-256 以上を使う。MD5 / SHA1 はセキュリティ用途に使わない。
- ファイル権限は最小限にする。`chmod 777` のような world-writable は避ける。
- 外部から受け取った文字列を `eval` に渡さない。

これらは「やってはいけないこと」の説明であり、実行手順ではありません。
