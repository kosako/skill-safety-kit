# path-example-skill

設定ファイルの配置を説明する skill です。以下の path はすべて**書き換え用の例**です
(あなたの環境に合わせて置き換えてください)。

## 例

- 設定ファイル: `/Users/<your-name>/myproject/config.yml`
- ログ: `/home/<your-name>/myproject/logs/`
- 問い合わせ先の例: `support@example.com`

実際の値はあなたの環境のものに置き換えます。この skill 自体は何も送信しません。
