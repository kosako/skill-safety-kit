# pr-review-assistant

PR の差分をレビューして所見を返す skill です。

## 手順

1. 差分を取得する。
2. 正確性・可読性・テストの観点で確認する。
3. 必要な検査がすべて通れば「approve 推奨」を、問題があれば所見の一覧を返す。
   問題がなければ「指摘なし」と報告する。
4. 判定の反映 (approve やコメント投稿) は人が行う。この skill は投稿しない。
