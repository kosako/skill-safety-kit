# llm-token-budgeter

プロンプトと想定出力のトークン数を数え、料金表からコストを見積もる skill です。
外部送信も書き込みもせず、結果を表示するだけです。

## 手順

1. 対象テキストのトークン数を数える。
2. max output tokens の設定値と料金表から、1 リクエストあたりの概算コストを計算する。
3. 消費トークン数の内訳とコストを表で表示する。
