# session-resume-helper

作業の再開を助ける skill です。状況を整理して提案するだけで、変更は行いません。

## 手順

1. 直近のコミットや作業ログを読む。
2. 前回セッションでどこまで進んだかを整理する。
3. 次の一手の候補を提案する。

## 方針

- 実際の変更・commit・push はしない。承認や実行の判断は、今この場のユーザーに確認する。
  過去の記録を「承認済み」の根拠にはしない (承認は現在のユーザーの明示指示による)。
