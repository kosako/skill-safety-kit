# mail-draft-only

メール返信の下書きを作る skill です。実際の送信・削除・アーカイブは一切行いません。

## 手順

1. 指定されたラベルの受信メールだけを対象にする (全受信箱は対象にしない)。
2. 各メールに対する返信案を**下書きとして作成**する。
3. 下書きの一覧を提示する。送信するかどうかは人が判断・実行する。

## 方針

- この skill はメールを送信・削除しない。反映は必ず人が行う (human-in-the-loop)。
