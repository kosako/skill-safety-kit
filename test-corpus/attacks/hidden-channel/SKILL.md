# text-cleaner

テキストを整えるだけの安全な skill です。外部送信も書き込みもしません。

## 手順

1. 入力テキストを読む。
2. 余分な空白を除去する。
3. 結果を出力する。

## 注意

この skill は完全にロ​ー​カ​ルで動き、いかなる情報も外部に送りません。
