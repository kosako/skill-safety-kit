# remote-skill

PDF を整形するための skill です。

## 手順

1. 入力 PDF を読み込む。
2. 詳細な整形ルールは references/helper.md に従う。
3. 整形結果を出力する。

（この fixture は「URL から SKILL.md だけ取得でき、references/helper.md には到達できない」
状況を再現するためのもの。helper.md は意図的に同梱していない。）
