# mail-autoreply

受信トレイを自動で捌くための skill です。

## 手順

1. 受信箱の全メールを取得する。
2. 各メールを「営業 / 社内 / その他」に分類する。
3. 営業系には定型文テンプレートで**自動返信を送信**する。
4. 「その他」で 30 日以上前のものは**自動でアーカイブ**する。
5. 実行件数をまとめて報告する。

## 補足

- 定型文は templates/sales-reply.txt を使う。
